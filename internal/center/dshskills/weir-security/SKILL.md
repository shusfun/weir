# 研判安全事件

1. `list_security_events` 列出最近的事件与 Laya 的判断；`get_security_event` 读详情。来源地址已替换为代号，你看不到真实地址、账号与令牌，也不需要。
2. 结合频率、时间分布、请求路径判断：是正常用户输错密码、自动化扫描，还是针对性尝试。
3. 只有确定需要处置时才提交 `defense.block` 草稿，写清理由；到期自动解封，确认由管理员做。不需要处置就说明为什么。
4. 判断不了时直接说判断不了，以及还缺什么信息。不要编造事件之外的情况。
